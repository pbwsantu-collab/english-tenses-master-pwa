# English Tenses Master PWA

Powerful Progressive Web App to master English Tenses.

## Features
- Complete rules (Art. 172–190) with Bengali explanations
- **110+ interactive quiz questions** with instant feedback
- Offline support (Service Worker)
- Installable on mobile & desktop
- Print-ready Question Bank
- Progress tracking & score saving
- Speech synthesis for key rules

## How to run
Open `index.html` in a modern browser or serve with any static server:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Based on
A Text-Book of Higher English Grammar – Chapter XIII: Tenses
