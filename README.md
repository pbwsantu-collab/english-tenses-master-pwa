# English Tenses Master PWA

Live: https://pbwsantu-collab.github.io/english-tenses-master-pwa/

Complete Progressive Web App for **Chapter XIII — Tenses** (Higher English Grammar), with Bengali explanations.

## Features
- All rules (Art. 172–190), notes, tables and conjugations
- Confusing verbs (lie/lay, hang, fly/flee/flow, born/borne, etc.)
- Full conjugation of *to love* (active & passive)
- **200 practice questions** with answers and Bengali explanations
- Print-ready layout
- Offline PWA (installable)

## Based on
A Text-Book of Higher English Grammar – Chapter XIII: Tenses
